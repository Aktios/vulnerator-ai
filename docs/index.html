An OODA pentest driven by Hermes talking directly to a Kali container via MCP.

What it is

An OODA (Observe-Orient-Decide-Act) pentest loop where the driving brain is Hermes (Nous Research) and the tools run on a Kali governed by an MCP server. Hermes decides what to run and launches it directly against the target.

A deliberately minimal design: no core, no REST API, no UI, no gates. Three containers — the agent and two MCP servers — driving the engagement end to end.

Architecture

Three containers.

  • kali

    Deterministic runtime for pentest tools: nmap, nuclei, sqlmap, ffuf, gobuster, Prowler, ScoutSuite and more. Exposes the kali-mcp server.

  • playwright-mcp

    A real headless Chromium browser exposed over MCP — the web flank for navigation, DOM and interaction, with zero native toolsets.

  • ooda-agent

    Hermes as the OODA loop driver and client of both MCP servers, running the pentest tools directly.

Built with

  • Docker
  • Hermes Agent · Nous Research
  • Kali Linux

⚠ Warning

By default this product has no guardrails: no scope-guard, no consent, no authorization gate. There is an opt-in scope-guard you can enable, but by default nothing validates the scope. Use this only against explicitly authorized targets and in a controlled environment. All responsibility for the scope rests with the operator.
