5. Vulnerabilidad — Detalles Técnicos

  • CVE: CVE-2026-109618 / CVE-2026-109619 — PHP2Shell
  • Versión afectada: PHP 8.2.34 (confirmada en target)
  • Versión parcheada: PHP 8.2.35+, 8.3.24+, 8.4.6+
  • Mecanismo: El handler session.upload_progress (habilitado por defecto) almacena el filename del upload multipart crudo (sin sanitizar) en el fichero de sesión sess_<SID>. Si la aplicación incluye ese fichero (LFI), el código PHP se ejecuta.
  • Condiciones habilitadoras en el lab:
    • session.upload_progress.enabled=On
    • session.upload_progress.cleanup=Off (persistencia del payload)
    • session.use_strict_mode=0 + session.use_only_cookies=0 (session fixation)
    • LFI sin sanitizar en /vuln.php (include($_GET['page']))
    • display_errors=On (facilitó debugging, no necesario para la explotación)

6. Recomendaciones de Remediación

  1. Actualizar PHP a 8.2.35+ (parche oficial que corrige CVE-2026-109618/109619)
  2. session.upload_progress.enabled=Off si la aplicación no usa seguimiento de progreso de uploads
  3. session.upload_progress.cleanup=On (comportamiento seguro por defecto, evita persistencia)
  4. session.use_strict_mode=1 y session.use_only_cookies=1 (previene session fixation)
  5. Corregir el LFI en /vuln.php:
    • Implementar allowlist de ficheros incluibles
    • Rechazar wrappers peligrosos (php://, phar://, data://, ...)
    • Validar y normalizar paths con realpath() + prefijo obligatorio
    • Deshabilitar display_errors en producción
