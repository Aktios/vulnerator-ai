5. Vulnerability — Technical Details

  • CVE: CVE-2026-109618 / CVE-2026-109619 — PHP2Shell
  • Affected version: PHP 8.2.34 (confirmed on target)
  • Patched version: PHP 8.2.35+, 8.3.24+, 8.4.6+
  • Mechanism: The session.upload_progress handler (enabled by default) stores raw multipart upload filename (unsanitized) in session file sess_<SID>. If application includes that file (LFI), PHP code executes.
  • Enabling conditions in lab:
    • session.upload_progress.enabled=On
    • session.upload_progress.cleanup=Off (payload persistence)
    • session.use_strict_mode=0 + session.use_only_cookies=0 (session fixation)
    • Unsanitized LFI in /vuln.php (include($_GET['page']))
    • display_errors=On (aided debugging, not required for exploitation)

6. Remediation Recommendations

  1. Upgrade PHP to 8.2.35+ (official patch fixing CVE-2026-109618/109619)
  2. session.upload_progress.enabled=Off if application doesn't use upload progress tracking
  3. session.upload_progress.cleanup=On (safe default behavior, prevents persistence)
  4. session.use_strict_mode=1 and session.use_only_cookies=1 (prevents session fixation)
  5. Fix LFI in /vuln.php:
    • Implement allowlist for includable files
    • Reject dangerous wrappers (php://, phar://, data://, ...)
    • Validate and normalize paths with realpath() + mandatory prefix
    • Disable display_errors in production
